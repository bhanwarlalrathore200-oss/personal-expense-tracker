# Personal Expense Tracker

A simple Java console-based project
for managing daily expenses.

## Features
- Add Expense
- View Expenses
- Calculate Total Expenses
- Delete Expense

## Technologies
- Java
- VS Code
- ArrayList
- OOP

## How to Run
1. Install Java JDK.
2. Open Main.java in VS Code.
3. Run the program.
